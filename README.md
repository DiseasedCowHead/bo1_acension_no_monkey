# bo1_acension_no_monkey
Removes monkeys from Call of Duty Black Ops 1 zombies map Ascension

Add the folder 'ascension_no_monkey' to your black ops mods folder.
By default, BO1 does not support mods unless you install Game_mod (aka LinkerMod) into your BO1 directory.
If you use plutonium, you can just simply drop itento
