# bo1_acension_no_monkey
Removes monkeys from Call of Duty Black Ops 1 zombies map Ascension and replaces them with dog rounds.

Add the folder 'ascension_no_monkey' to your black ops mods folder.

By default, BO1 does not support mods unless you install Game_mod (aka LinkerMod) into your BO1 directory.

If you use Plutonium, you can just simply drop into your %LocalAppData%\Plutonium\storage\t5\mods folder and load it that way through Plutonium.
